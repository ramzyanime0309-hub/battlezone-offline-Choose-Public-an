# Death Race 2D — Godot 4

A separate 2D top-down arcade racing project. The previous Unity and 3D Godot projects are preserved.

## Current prototype
- Top-down oval race circuit with road edges, lane markings and start/finish line.
- Player car with acceleration, steering, braking, drift and rechargeable nitro.
- Three AI rival cars.
- Three-lap checkpoint race, countdown and finish state.
- Touchscreen controls and keyboard controls.
- Offline single-player; no accounts, purchases or online multiplayer.

## Open
Open this folder in Godot 4.3 or compatible Godot 4.x and run the main scene at scenes/race_2d.tscn.

Keyboard: W/Up accelerate, S/Down brake, A/D or arrows steer, Shift nitro, Space drift. On mobile, use the on-screen buttons.

## Status
This is a new 2D greybox prototype using code-drawn track and placeholder car shapes. It has not yet been run in the Godot editor or tested on an Android phone. The project is set to landscape and GL Compatibility. Android export templates and SDK setup are still needed to make an APK.
